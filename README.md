# ⏳ Countdown Timer — Day 13

A simple, colorful, and responsive countdown timer built using HTML, CSS, and JavaScript.

## ✨ Features

- Live countdown updated every second
- Custom target date and time
- Displays days, hours, minutes, and seconds
- Handles invalid or past dates
- Shows a message when the countdown finishes
- Responsive layout for mobile and desktop
- Colorful gradient design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

day-13-countdown-timer/
├── index.html
├── style.css
└── script.js

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Select a future date and time.
5. Click **Start Countdown**.

No additional libraries or installations are required.
